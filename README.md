# Smart Home Prototype
A home automation system using multiple sensors for lighting, 
temperature, motion, and fire detection.

## Features
- Automatic lighting control based on ambient light sensor
- Temperature monitoring with display
- Motion detection
- Fire detection and alert
- Door control using servo motors
- Keypad password for home security access

## Components
- Arduino UNO
- Temperature Sensor
- Ultrasonic Sensor (HC-SR04) for motion detection
- Light Sensor (LDR)
- LM35 Temperature Sensor
- Servo Motors (door control)
- Keypad
- LCD Screen
- LED Lights
- Buzzer (fire & motion alert)

## Tools
- Arduino IDE
- C++
